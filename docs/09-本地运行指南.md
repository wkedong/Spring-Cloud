# 09 · 本地运行指南

> 目标：把全套微服务在你本机跑起来，并逐项验证（对应 docs/00 的验证入口清单）。

## 0. 前置条件

- JDK 8~17（本项目按 Java 8 编译；用 17 编译运行也可以，`java.version=1.8`）
- Maven 3.6+（或各模块自带的 `.mvn/wrapper`）
- MySQL 8.0（**不要用比 8 更新的版本**，Flyway 8.5 校验不通过）
- Zipkin 二选一：Docker（推荐）或官方 exec jar

## 1. 准备 MySQL（三种方式任选）

**方式 A：docker compose（推荐，一键全带）**

```bash
docker compose up -d        # mysql(3306, 自动执行 sql/InitSQL.sql) + zipkin(9411)
```

**方式 B：已有 MySQL 8 实例**

```bash
mysql -uroot -p < sql/InitSQL.sql   # 建 spring_cloud_config / spring_cloud_demo 两库
```

**方式 C：临时实例（无 root 权限演示用）**

```bash
mysqld --initialize-insecure --datadir=/tmp/mysql-data
mysqld --datadir=/tmp/mysql-data --port=3306 &
```

## 2. 构建

```bash
mvn clean package -DskipTests
```

## 3. 启动 Zipkin（若用方式 B/C 准备数据库）

```bash
docker compose up -d zipkin
# 或下载官方发行版：
# curl -LO https://repo1.maven.org/maven2/io/zipkin/zipkin-server/3.4.2/zipkin-server-3.4.2-exec.jar
# java -jar zipkin-server-3.4.2-exec.jar
```

> 端口注意：早期自建 zipkin 模块曾用 6040，本版本统一为官方默认 9411。

## 4. 按依赖顺序启动服务（每条一个终端）

```bash
# ① 注册中心
java -jar eureka/target/eureka-0.0.1-SNAPSHOT.jar
# ② 配置中心（首次启动 Flyway 自动建 PROPERTIES 表并灌数据）
java -jar config/target/config-0.0.1-SNAPSHOT.jar
# ③ 服务提供者（可起两个实例观察负载均衡）
java -jar service-producer/target/service-producer-0.0.1-SNAPSHOT.jar --server.port=6070
# java -jar service-producer/...jar --server.port=6080   ← 第二实例
# ④ 四个消费者
java -jar service-consumer/target/service-consumer-0.0.1-SNAPSHOT.jar
java -jar service-consumer-feign/target/service-consumer-feign-0.0.1-SNAPSHOT.jar
java -jar service-consumer-ribbon/target/service-consumer-ribbon-0.0.1-SNAPSHOT.jar
java -jar service-consumer-ribbon-hystrix/target/service-consumer-ribbon-hystrix-0.0.1-SNAPSHOT.jar
# ⑤ 网关（最后启动，等注册表同步约 15~30s）
java -jar zuul/target/zuul-0.0.1-SNAPSHOT.jar
```

> IDE 里跑也可，但注意配置文件在 `src/main/resources/`（本分支已按 Maven 标准目录归位）。

## 6. 常见问题

| 现象 | 原因与解法 |
| --- | --- |
| 业务服务起不来，报连不上 6010 | 配置中心没起/没先起——启动顺序必须 eureka → config → 业务 |
| `FlywayException: Unsupported Database` | MySQL 版本 > 8（如 9.x）；教学环境请用 MySQL 8.0，或临时 `--spring.flyway.enabled=false` 并手工建表 |
| `Public Key Retrieval is not allowed` | MySQL 8 认证插件问题，URL 已带 `allowPublicKeyRetrieval=true`；自改连接串时别删 |
| 调用报 `No servers available for service` | provider 未注册/刚重启注册表未同步——等 15~30s 再试；确认 eureka 控制台里有实例 |
| 网关 503 | 同上：`lb://` 目标服务在注册表里暂无实例 |
| gateway 启动报 MVC 冲突 | zuul 模块里混入了 `spring-boot-starter-web`（见 docs/06 迁移三坑） |
| `TraceCircuitBreaker cannot be cast ...` | 注入了具体类 `Resilience4JCircuitBreakerFactory`，改成抽象 `CircuitBreakerFactory`（见 docs/05） |
| multipart 报 `FileNotFoundException ... tmp` | `transferTo()` 之后再读原 MultipartFile；先转发后归档（见 docs/04） |
